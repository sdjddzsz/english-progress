### 1.3 真相与处置（2026-10-15 14:28 已解决）

- `describe_table book_words` 显示 **6 个考查列全部存在**（另有历史遗留的重复 snake_case 列

  由于 `select *` 不引用具体列，读不受影响；写入 PATCH 带新列才炸。

  SELECT 成功（8296 行全列可用，353 行已有 lastQuizAt）→ 再走应用同链路（SDK→PostgREST）验证
  显式 select 新列无 PGRST204；anon 读 0 行 = RLS 正常挡未登录。
- **验收归用户**：登录应用连答几题 → Today「今日待完成」应随过关下降。
